## 10. dsa-02-two-pointers.mp4  →  playlist: DSA in Java

**Title**

```
Two Pointers: Solve This Interview Question in O(n) (Java) | DSA #2 #shorts
```

**Description**

```
Find two numbers in a sorted array that add up to a target. The brute-force way checks every pair: O(n²). The two-pointer trick puts one pointer at each end. If the sum is too small, move the left pointer right; if it's too big, move the right pointer left. Each step throws away a number that can't be part of the answer, so it finishes in a single pass: O(n) time, O(1) extra space.
```
