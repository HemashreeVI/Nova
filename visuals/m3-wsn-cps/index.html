Module 3 · 1.1–1.2
What is a WSN?

Definition

A large network of small, resource-constrained sensor nodes that sense, process and communicate wirelessly, deployed in a sensing field to achieve an application objective.

Purpose: implement application goals (monitor temperature, intrusion…) in a specific field
Expansion: extends the Internet into the physical world → cyber-physical environment

Nodes / motes

Spatially distributed autonomous devices using sensors to monitor conditions

Communication

Node ↔ node (multi-hop) or directly to a base station

Base stations / gateways

Forward sensor data to a monitoring centre / decision system (wireless or wired)

Module 3 · 2
Network topologies
Topology = connectivity graph: vertices = nodes, edges = one-hop links

Star

✓ simple, easy, low latency
✗ BS = single point of failure, limited scalability, far nodes use more energy
e.g. smart home, 6 sensors + hub

Cluster-tree

✓ scalable, energy-efficient, less BS traffic
✗ multi-hop latency; CH failure cuts its cluster
e.g. forest monitoring by area

Mesh

✓ reliable, robust, self-healing, scalable
✗ complex management, routing-overhead energy
e.g. industrial plant monitoring

Module 3 · 6.1–6.3
MANET, WSN and M2M

MANET

Self-configuring network of mobile devices that move freely.
• Every device is a router
• No fixed infrastructure, dynamic topology
• Heterogeneous protocols
e.g. soldiers' radios, VANET

WSN = special MANET

Spatially distributed sensing devices monitoring conditions.
• Sensors collaborate beyond any single sensor
• Mobility improves tracking & data collection
e.g. environment, disaster response

M2M

Devices exchange info and act without human intervention.
• RFID · sensors
• links: ZigBee, WiMAX, Wi-Fi, cellular
• computing software decides
e.g. smart meter → utility server
