MODULE 6 · COOPERATIVE RELAYING
Multi-Relay Power Allocation
Lagrangian model · Decode-and-Forward (DF) relays
Goal: solve the two-relay exam example
Slide 2
System model
DF relays — half-duplex
Channel gains h_sri (S→Ri), h_rid (Ri→D)
Powers: Ps at source, Pri at relay i
Ps + Σ Pri ≤ P_total
total power constraint
Slide 3
Rate: each relay is a two-hop bottleneck
SNR_i = min( Ps·h_sri/N0 , Pri·h_rid/N0 )
the weaker hop decides
R = ½ · log2( 1 + max_i SNR_i )
½ → two half-duplex slots
Objective: choose Ps, Pri to maximize R
Slide 4
Lagrangian formulation
Let t_i = target SNR across the hops of relay i
Constraints
Ps·h_sri/N0 ≥ t_i hop 1 reaches target
Pri·h_rid/N0 ≥ t_i hop 2 reaches target
Ps + Σ Pri ≤ P_total
L = ½·log2(1 + max_i t_i) − (multiplier × constraints)
Slide 5
Optimality: balance the SNR of both hops
Ps·h_sri = Pri·h_rid
for every active relay i ∈ A
⇒ Pri = Ps · (h_sri / h_rid)
Ps + Σ_{i∈A} Ps·(h_sri/h_rid) = P_total
solve for Ps, then each Pri
Slide 6
Relay selection rule
g_i = h_sri·h_rid / ( h_sri + h_rid )
bottleneck metric for each relay
like two resistors in parallel — small if either hop is weak
Larger g_i → better balanced two-hop path
Select the top-k relays (typical k = 1 or 2) for power allocation
Slide 7
Closed-form optimal powers
Ps · ( 1 + Σ_{i∈A} h_sri/h_rid ) = P_total
Ps = P_total / ( 1 + Σ h_sri/h_rid )
Pri = Ps · ( h_sri / h_rid )
Slide 8 · worked example
Two relays, P_total = 1, N0 = 1
Relay 1: h_s1 = 0.5, h_1d = 2
Relay 2: h_s2 = 0.3, h_2d = 0.7
Step 1 · relay metric g_i
g_1 = (0.5×2)/(0.5+2) = 1/2.5 = 0.4
g_2 = (0.3×0.7)/(0.3+0.7) = 0.21/1 = 0.21
0.4 > 0.21 ⇒ choose Relay 1 ✓
Step 2 · source power
ratio = h_s1/h_1d = 0.5/2 = 0.25
Ps = 1 / (1 + 0.25) = 1/1.25 = 0.8
Step 3 · relay power
P1 = 0.8 × 0.25 = 0.2 check: 0.8 + 0.2 = 1 ✓
Check
Are the hops balanced?
R = ½·log2(1 + 0.4) = ½·log2(1.4) ≈ 0.24 bit/s/Hz (computed here, not on the slide)
Relay 1's second hop is strong (h_1d = 2) → it needs little power; most budget goes to the weaker source hop.
Slides 9–11
Cooperative transmission
Exploits the broadcast nature of wireless
Relays = virtual antenna of the source
MIMO-like system
Multi-user and multi-route diversity
Industrial standard: IEEE WiMAX 802.16j
Two phases
Phase 1: sender → destination and relay (both hear it)
Phase 2: relay → destination (retransmitted signal)
Slide 12 · summary
Exam recipe
Multi-relay DF optimization reduces to balancing SNR per hop
Use the relay quality metric g_i for selection
Closed-form power allocation for active relays
① g_i = h_sr·h_rd/(h_sr+h_rd) → pick largest
② ratio = h_sr/h_rd ③ Ps = P_total/(1+Σ ratio)
④ Pri = Ps·ratio ⑤ check Ps + ΣPri = P_total
