Why data-centric routing?

No unique IDs

Too many sensors for global IDs

Random deployment

Redundant transmission

Every sensor in an area sends the same data → energy wasted

Ask by WHAT the data is: "temperature > 40°C in region R" — not by WHICH node

Module 3 · 12.3
Flooding (baseline)
Broadcast to all neighbours until destination or max hop count · ✓ very simple, no routing or topology maintenance

Implosion

Same message reaches a node many times (D gets A's packet twice)

Overlap

Nodes sensing the same region send similar data

Energy exhaustion

Huge redundant traffic drains batteries

Module 3 · 12.4
Gossiping
Modified flooding: send to one random neighbour, which repeats

✓ Advantage

Fewer copies → avoids implosion

✗ Disadvantages

Propagation delay (random route); packet may move away or loop and fail

FloodingGossiping
Sends toAll neighboursOne random neighbour
ImplosionYesAvoided
DelayLowHigh
DeliveryAlmost guaranteedNot guaranteed (loops)
EnergyVery highLower
Module 3 · 12.5
SPIN — negotiation
ADV · "I have new data (metadata)"REQ · "I'm interested, send it"DATA · actual sensor data

✓ Advantages

Solves implosion, overlap, energy exhaustion; only single-hop knowledge

✗ Limitations

No delivery guarantee — stops at an uninterested middle node; not for mission-critical CPS

Module 3 · 12.6
Directed Diffusion
interest: type = vehicle · interval = 20 ms · duration = 10 s · rect = [-100, 100, 200, 400]

✓ Advantages

No unique addressing · caching cuts delay · energy-efficient, on-demand

✗ Limitation

Poor for continuous monitoring / real-time (battlefield, traffic, environment)

Module 3 · 13.1
LEACH — Low-Energy Adaptive Clustering Hierarchy

Clustering

1 CH + members; CH aggregates → BS

Random CH rotation

Probability-based; recent CHs less likely again

Aggregation

CH compresses member data

Module 3 · 13.1 · extra for full marks (not on slides)
LEACH CH election threshold
T(n) = P / [ 1 − P × (r mod 1/P) ] if n not CH in last 1/P rounds, else 0
Node becomes CH if random(0,1) < T(n) · P = desired CH fraction · r = current round
P = 0.05 → 1/P = 20CalculationT(n)
Round 00.05 / (1 − 0)0.05
Round 100.05 / (1 − 0.5)0.10
Round 190.05 / (1 − 0.95)1 → all remaining become CH

✓ Advantages

Energy efficiency · scalability · self-organising

✗ Disadvantages

Uneven random CHs · single-hop CH→BS · setup overhead (dynamic nets)
