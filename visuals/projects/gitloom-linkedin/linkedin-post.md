Your GitHub already knows what you've built. So why are you still hand-coding a portfolio?

I built GitLoom 🧵

Type a GitHub username and it reads the public repos, languages and recent activity, then weaves them into a portfolio website, live, in your browser. (The loom on the landing page actually weaves a new row for every letter you type.)

What you can do in the studio:
🎨 10 templates, from Editorial and Terminal to Brutalist and Aurora. Same data, completely different look
🖌️ Any accent colour, 9 headline fonts
↕️ Drag sections into your own order, or hand-pick which repos to feature
📱 A phone layout for every template
⌨️ Ctrl+K quick menu, project search, and a clean PDF résumé from the same data
🔗 Share links that rebuild your whole design straight from the URL
📦 Download ONE index.html and host it free on GitHub Pages

The part I'm proudest of: there's no backend. No sign-up, no server, no build step. Just HTML, CSS, vanilla JavaScript and the GitHub REST API, with caching and an optional token so the free API limit holds up.
