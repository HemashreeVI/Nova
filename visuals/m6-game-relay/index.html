Slide 4 · block 3
Game theory
Models competitive or cooperative behaviour among agents (devices / nodes)
Each device = player maximizing its utility (min delay, max throughput)
Nash Equilibrium: no player can improve without hurting others
Used for energy sharing, spectrum sharing, task scheduling, offloading
Slide 5 · block 4

Slides 6–10 · scenario
Smart traffic monitoring CPS
roadside IoT sensors (speed, density, pollution)cameras with edge processingautonomous vehicles (real-time data)cloud & edge controllers

Data management

Gathers vehicle count, air quality, congestion → aggregated at edge, preprocessed, uploaded periodically. Redundant/outdated data filtered locally to save bandwidth.

Resource allocation

Peak hours: edge node allocates bandwidth & time slots by priority (accident alerts > normal updates). Low-battery sensors get energy-efficient schedules.

Game theory

Sensors compete for the channel; each player chooses transmission power. Non-cooperative game: min interference, keep reliability → Nash Equilibrium.

Cooperative relaying

Sensor in a tunnel (weak signal) uses a nearby roadside sensor as relay; shared bandwidth → better connectivity, fewer retransmissions.

Slide 13
Game theory for energy optimization
Each device = player minimizing its own energy while keeping communication quality

Non-cooperative power control game

Each node adjusts power to minimize its own energy while avoiding interference.

Stabilizes at Nash Equilibrium.

Cooperative game model

Nodes share energy or relay data together.

High-energy nodes help weaker ones → energy-aware coalition.

Auction-based spectrum sharing

Nodes bid for bandwidth or power.

Efficient use instead of everyone at full power.

Slide 22
Direct link SNR
y_sd = √Ps · h_sd · x + n
γ_sd = Ps·|h_sd|² / N0
= signal power / noise power → the baseline relaying must beat
Slides 23 & 33
Amplify-and-Forward (AF)
Gain G = √( Pr / (Ps|h_sr|² + N0) )
γ_AF = (Ps|h_sr|² · Pr|h_rd|²) / ( Pr|h_rd|²·N0 + (Ps|h_sr|² + N0)·N0 )
AF: simple, but noise-amplifying
Slide 34
Decode-and-Forward (DF)
γ_SR = Ps|h_sr|²/N0 γ_RD = Pr|h_rd|²/N0
γ_DF = γ_SD + γ_RD (if relay decodes)
DF: better performance, higher complexity
