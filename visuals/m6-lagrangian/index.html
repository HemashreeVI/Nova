MODULE 6 · OPTIMIZATION
The Lagrangian Method
1 · Objective
What should the system maximize?
2 · Constraints
What limits must be respected?
3 · Lagrangian
Combine objective and limits
Worked example: maximize f(p) = 10p − p² subject to 0 ≤ p ≤ 3
Step 1
Start with a constrained problem
CPS objective
Choose relay power p to improve transmission performance while accounting for costs.
Constraint
0 ≤ p ≤ 3 — battery, hardware, or interference cap.
Maximize f(p) = 10p − p² s.t. p − 3 ≤ 0, p ≥ 0
p is a simplified normalized relay-power decision — not a calibrated radio model.
Step 2
Standard form: gᵢ(x) ≤ 0
GENERAL
Maximize f(x)
s.t. gᵢ(x) ≤ 0
EXAMPLE
f(p) = 10p − p²
g(p) = p − 3 ≤ 0
Why this form?
Attach one non-negative multiplier λᵢ to each constraint, and see which limits are active at the optimum.
p ≥ 0 is also a constraint — but here the optimum is not at p = 0.
Step 3
Build the Lagrangian
ℒ(x, λ) = f(x) − Σᵢ λᵢ·gᵢ(x), λᵢ ≥ 0
each λᵢ = a Lagrange multiplier
ℒ(p, λ) = 10p − p² − λ(p − 3)
ℒ = 10p − p² − λp + 3λ
Intuition: λ measures the marginal value of relaxing a binding limit.
Step 4
Why is the constraint term subtracted?
g(p) = p − 3 ≤ 0
If p > 3 → violated, and p − 3 becomes positive
−λ(p − 3), λ ≥ 0
acts like a penalty on ℒ
Max with gᵢ ≤ 0 → ℒ = f − Σλᵢgᵢ. Other books may flip signs — stay consistent.
Step 5
The four KKT conditions
1 · Stationarity
∂ℒ/∂p = 10 − 2p − λ = 0
2 · Primal feasibility
p − 3 ≤ 0 and p ≥ 0
3 · Dual feasibility
λ ≥ 0
4 · Complementary slackness
λ(p − 3) = 0
Obey the limits · multipliers ≥ 0 · a constraint gets λ > 0 only if it is active
Step 6
Solve the example
A
Ignore the constraint
f′(p) = 10 − 2p = 0 → p = 5
B
Check feasibility: 5 > 3 ✗
boundary → p* = 3
C
Multiplier from stationarity
10 − 6 − λ* = 0 → λ* = 4
✓
λ(p−3) = 4 × 0 = 0 ✓
D
f(3) = 30 − 9 = 21
Step 7
λ is a shadow price
DECISION
p* = 3
MAX UTILITY
21
MULTIPLIER
λ* = 4
cap 3 → 3 + ε ⇒ utility ≈ 21 + 4ε
check: f(3.1) = 31 − 9.61 = 21.39 ≈ 21 + 4×0.1 ✓ (our check)
Meaning: λ = the marginal value of relaxing a constraint.
Application
Cooperative relays in CPS
Goal: choose relay transmit powers to balance quality, energy and delay, while satisfying constraints.
Industrial sensors → CPS controller, via cooperative relays when the direct link is weak.
Define the objective
Weighted utility
max U(p₁,p₂) = αQ − βE − δD
Q
communication quality / reliability
E
energy consumed
D
end-to-end delay
α, β, δ ≥ 0 are weights — ↑α prioritizes reliability; ↑β prioritizes energy saving.
Add system constraints
Constraints → standard form
CONSTRAINTS
p₁ + p₂ ≤ Pmax
shared power budget
0 ≤ pᵢ ≤ Pᵢmax, i = 1,2
individual limits
Q(p₁,p₂) ≥ Qmin
minimum quality
STANDARD FORM (slack ≥ 0)
g₁ = Pmax − p₁ − p₂ ≥ 0
g₂ = Q − Qmin ≥ 0
g₃ᵢ = Pᵢmax − pᵢ ≥ 0
g₄ᵢ = pᵢ ≥ 0
each gets a multiplier = its influence on the optimum
Construct ℒ
The relay Lagrangian
ℒ = αQ − βE − δD
+ λ(Pmax − p₁ − p₂)
+ μ(Q − Qmin)
+ Σᵢ ηᵢ(Pᵢmax − pᵢ) + Σᵢ ρᵢpᵢ
λ ≥ 0 · power budgetμ ≥ 0 · quality thresholdηᵢ ≥ 0 · upper power limitρᵢ ≥ 0 · non-negativity
+ signs here because constraints are written as slack ≥ 0 — same idea, different convention.
Stationarity + KKT
∂ℒ/∂pᵢ = 0 for each relay
0 = α(∂Q/∂pᵢ) − β(∂E/∂pᵢ) − δ(∂D/∂pᵢ)
− λ + μ(∂Q/∂pᵢ) − ηᵢ + ρᵢ
marginal quality benefit = marginal energy/delay cost + active constraints
1 · Stationarity ∂ℒ/∂pᵢ = 0
2 · Primal all original constraints hold
3 · Dual λ, μ, ηᵢ, ρᵢ ≥ 0
4 · Comp. slackness λ(Pmax−p₁−p₂)=0; μ(Q−Qmin)=0
inactive constraint → multiplier 0 · active → may be positive
Illustrative model
Computing the derivatives
Q = log₂(1 + γ₀ + a₁p₁ + a₂p₂)
E = e₁p₁ + e₂p₂ (delay ignored)
∂Q/∂pᵢ = aᵢ / [ ln(2)·(1 + γ₀ + a₁p₁ + a₂p₂) ]
∂E/∂pᵢ = eᵢ
→ substitute into stationarity, solve jointly with KKT
How to solve
Practical workflow
1Specify Q, E and D using the wireless-system model
2Define power limits and the quality threshold
3Construct ℒ and calculate derivatives
4Solve stationarity, feasibility, complementary slackness
5Check the solution against every constraint
Real DF systems may also need source–relay and relay–destination constraints, interference, and half-duplex factors.

QuestionCooperative modelNon-cooperative model
Who optimizes?Coalition / system jointlyEach player separately
ObjectiveShared utility U(A, P)Individual Uᵢ(Pᵢ, P₋ᵢ)

U(A,P) = αQ − βE − δD · Pᵢ,min ≤ Pᵢ ≤ Pᵢ,max · D ≤ Dmax · E ≤ Emax · Q ≥ Qmin
Caution: KKT ⇒ global optimum only if the problem is convex; non-convex radio models → local candidates.
Game theory = strategic interaction · Lagrangian = constrained optimization
Summary
Derivation in five steps
1Define objective: reliability benefit − energy − delay
2Write constraints as gᵢ(x) ≤ 0
3Build ℒ = f(x) − Σ λᵢgᵢ(x), λᵢ ≥ 0
4Apply KKT: stationarity, primal, dual, complementary slackness
5Solve & interpret λ — example: p* = 3, f = 21, λ = 4
