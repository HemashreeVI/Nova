## 2. wb-e2e-encryption.mp4  →  playlist: Cybersecurity in 60 Seconds

**Title**

```
How Your Group Chat Is Encrypted (Even WhatsApp Can't Read It) 🔐 #shorts
```

**Description**

```
End-to-end encryption means only the people in the chat can read the messages. Each phone makes a pair of keys: a public key it shares, like an open padlock, and a private key that never leaves the phone. Your phone locks each message with keys only the recipients can open, so the server only ever passes along scrambled data. The keys keep changing as you chat, so even a stolen key can't unlock old messages.

## 3. wb-battery.mp4  →  playlist: Vision & Robotics in 60 Seconds

**Title**

```
Why Your Phone Battery Dies Faster Every Year 🔋 #shorts
```

**Description**

```
Your phone runs on a lithium-ion battery. Charging pushes lithium ions from one side of the battery to the other, and using the phone lets them flow back. Every charge cycle, a few ions get trapped in a thin layer that slowly builds up inside, so fewer ions are left to carry charge. That's why capacity drops over time, often to around 80% after a few hundred full cycles. Heat and sitting at 100% speed it up, so avoid heat and use your phone's optimized or limited charging.

**Title**

```
What WhatsApp Ticks Really Mean ✔✔ Single, Double, Blue #shorts
```

**Description**

```
One grey tick means your message reached WhatsApp's server. Two grey ticks mean it was delivered to the other person's phone. Two blue ticks mean they opened the chat and read it, if read receipts are on. If their phone is offline, the server holds the message and delivers it as soon as they reconnect, and each phone sends a small receipt back so your ticks update.

## 5. wb-binary-search.mp4  →  playlist: DSA in Java

**Title**

```
Binary Search: Find 1 Person in 8 Billion in 33 Guesses 🔍 (Java) | DSA #3 #shorts
```

**Description**

```
Binary search finds an item in a sorted list by always checking the middle. If the target is bigger, throw away the left half; if it's smaller, throw away the right half. Every guess halves what's left, so even 8 billion sorted names need at most 33 guesses (2³³ is about 8.6 billion). That's O(log n) time, and it only works when the data is sorted.
